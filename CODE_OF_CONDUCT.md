# Code of conduct

## The short version

Be decent. Assume the other person is trying to do good work.

## What that means here

- Critique the code, the method or the number — not the person.
- Disagree with evidence. "This threshold is wrong because the drill recorded X"
  is useful; "this is bad" is not.
- Say when you are unsure. A question asked early is cheaper than a wrong fix.
- No harassment, personal attacks, or unwelcome attention of any kind.

## Scope

This applies to issues, pull requests, discussions and any other space that
represents the project.

## Reporting

Report conduct problems by opening a GitHub issue, or privately through
GitHub's report function if the issue involves a maintainer. Reports are handled
as discreetly as the situation allows.
